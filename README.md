# 매입 계약 현황 대시보드

매입 계약 진행 현황(엑셀)을 웹페이지로 보여주는 내부 공유용 대시보드입니다.
빌드 과정이 없는 정적 페이지(`index.html` + `data.js`)입니다.

> ⚠️ 계약·거래처 정보가 들어 있으므로 저장소는 반드시 **Private** 으로 유지하세요.

## 보는 법
`index.html` 을 브라우저로 열면 됩니다. (서버 불필요)

## 데이터 갱신 방법
1. 엑셀(매입 계약 진행 현황)을 최신으로 수정합니다.
2. 아래 명령으로 `data.js` 를 다시 만듭니다.
   ```bash
   pip install openpyxl
   python3 scripts/build_data.py "엑셀파일.xlsx"
   ```
3. 변경사항을 커밋하고 올립니다.
   ```bash
   git add data.js
   git commit -m "계약 현황 업데이트"
   git push
   ```

엑셀 원본(`*.xlsx`)은 `.gitignore` 로 제외되어 있어 저장소에는 올라가지 않습니다.
(단, `data.js` 안에 엑셀 내용이 그대로 들어가므로 저장소 공개 범위에 유의하세요.)

## 현재 상태 판정 규칙
엑셀의 계약 단계 열(법무검토 요청 → 계약 품의 → 계약서 송부 → 계약서 회수 → 계약보증증권) 중
**가장 멀리 완료(O 또는 '각서 대체')된 단계**를 기준으로 합니다.

| 상태 | 조건 |
|---|---|
| 법무검토 · 품의 전 | 법무검토까지만 했거나 아무것도 없음 |
| 품의 완료 · 송부 대기 | 계약 품의 완료 |
| 송부 완료 · 회수 대기 | 계약서 송부 완료 |
| 회수 완료 · 보증증권 대기 | 계약서 회수 완료 |
| 체결 완료 | 계약보증증권까지 완료 |
| 홀딩 | 비고에 '홀딩' 이 들어 있음 (다른 단계보다 우선) |

셀에 `X` 가 있으면 "확인 필요"로 표시됩니다.

## 디자인 토큰
색상·간격·글자 크기·라운드는 `index.html` 맨 위 `<style>`의 `:root` CSS 변수로 관리합니다. Dark 모드는 같은 변수 이름에 다른 값을 넣어 정의합니다.

| 구분 | 변수 | 비고 |
|---|---|---|
| 상태 색 | `--done` / `--progress` / `--hold` / `--danger` | 체결 완료 / 진행 중 / 홀딩 / 확인 필요 (의미 고정) |
| 단계 램프 | `--st-1` ~ `--st-5` | 1단계(연한 블루) → 체결 완료(짙은 블루) |
| 간격 | `--sp-1` ~ `--sp-8` | 4px 단위 |
| 글자 | `--fs-title` `--fs-section` `--fs-kpi` `--fs-body` `--fs-sub` `--fs-meta` | Pretendard Variable 사용 |

## 파일 구성
- `index.html` : 대시보드 화면
- `data.js` : 엑셀에서 변환된 데이터 (자동 생성)
- `scripts/build_data.py` : 엑셀 → `data.js` 변환 스크립트
- `fonts/` : Pretendard Variable 글꼴 (SIL OFL 1.1 라이선스, 같은 폴더의 라이선스 파일 참고)
